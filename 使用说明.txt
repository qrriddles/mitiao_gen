随心灯谜 · 谜条制作工具
版本：v1.1.0（2026-10-24）— 隐私与稳定性维护版

一、离线使用
1. 将整个 ZIP 压缩包解压到同一个文件夹。
2. 双击 index.html，在 Chrome 或 Edge 中打开。
3. 点击「下载 Excel 谜稿模板」，将谜面写在 B 栏、谜目写在 C 栏、谜底写在 D 栏，A 栏可填题号。
4. 选择已填写的 Excel 文件，查看露春检查结果，必要时下载报告。
5. 可勾选／取消「显示题号」，然后生成 PPTX。
6. 在 Microsoft PowerPoint 打开并校对字体、竖排和换列，仍可人工编辑。

二、上线网站
将整个解压后的文件夹内容放到任意支持静态网站的空间即可，无须后端服务。
本工具的 Excel 分析和 PowerPoint 生成均在浏览器中完成。

三、注意事项
1. 不要只复制 index.html 文件。jszip.min.js、template-data.js、app.js、谜稿模板.xlsx 都要一起保留。
2. 检查的是 B、D 两栏共有的汉字，并非灯谜含义正确性判断。
3. B、C 都没有内容的行不生成 PPT；仅填 B 或仅填 C 则会提示，但仍生成。
4. 生成后请在 Microsoft PowerPoint 中确认字体、竖排和换列效果。

四、版本规则
v0.1.2：第一个测试原型。
小修正（例如细微字号／间距修正）递增末位：v0.1.2。
加入新功能（例如高级排版设置）递增中间位：v0.2.0。
经过实际使用确认可公开发布，进入 v1.0.0。
今后每次合作改版，由 ChatGPT 建议版本号、同步更新界面和版本记录；您保有最终发布决定权。

关闭或刷新页面后，请重新上传 Excel 文件；网页不会保留上传数据。

本版：下载的 PPTX 以 Excel 文件名及本机生成日期时间命名；仅有谜底的行将出现在提示中。


v1.0.1：仅接受 .xlsx 文件，单个 Excel 文件上限 10 MB；损坏文件会提示重新选择；超过 300 条谜条时，生成前需要确认。

v1.0.2：移除 VBA、旧作者资料与嵌入的 KaiTi 字体；Excel 展开后总量上限 40 MB，单个内部文件不超过 16 MB，最多处理 1500 行谜稿。
字体说明：幻灯片仍指定 KaiTi（楷体），但不附带字体文件。若设备未安装 KaiTi，PowerPoint 可能使用替代字体，影响版面；建议在安装 KaiTi 的 Windows / Office 电脑上打开并检查。请勿自行从其他电脑复制 Microsoft 字体文件。


v1.1.0：调整 PowerPoint 模板的 Base64 解码方式，以改善手机浏览器兼容性。


v1.1.0：新增 Google Slides 兼容版（可编辑 PPTX）；导入 Google Slides 后请逐页检查字号、间距与换列。标准 PowerPoint 版建议使用本机安装的楷体（KaiTi），工具不包含字体文件。
